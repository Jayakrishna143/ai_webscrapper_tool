# Agentic Web Scraper

A pure-Python, framework-free Agentic workflow built on the Model Context Protocol (MCP). This system utilizes a large language model to autonomously write, execute, test, and debug web scraping code based on natural language extraction goals. 

By avoiding heavy agentic frameworks and utilizing a standard ReAct (Reason-Act-Observe) loop, this project provides a highly transparent, self-correcting data pipeline architecture.

## Architecture Overview

The system is strictly divided into an execution environment and a cognitive engine, communicating via stdio using the Model Context Protocol.

* **`mcp_server.py` (The Environment):** Acts as the secure execution sandbox. It exposes two core tools to the LLM:
    * `fetch_html`: Intelligently fetches webpage content using `requests` for static sites or headless `Selenium` for JavaScript-heavy applications, cleaning the HTML to preserve LLM context.
    * `run_extraction_code`: Dynamically executes BeautifulSoup Python scripts generated by the LLM in a localized namespace. It captures and returns standard output, successful data arrays, or full error tracebacks.
* **`agent_loop.py` (The Cognitive Engine):** Manages the pure-Python ReAct loop. It passes state history to the Groq inference engine, parses requested tool calls, invokes the MCP server, and feeds the results back into the loop until the target JSON data is successfully extracted.
* **`app.py` (The Interface):** A Streamlit application that provides real-time visibility into the agent's reasoning, tool invocations, and code execution, outputting the final structured JSON and the successful Python script.

## Prerequisites

* Python 3.10 or higher
* Google Chrome installed on your machine (for Selenium dynamic rendering)
* A valid Groq API Key

## Required Libraries

Install the necessary dependencies using pip:

```bash
pip install groq mcp streamlit beautifulsoup4 requests selenium webdriver-manager python-dotenv
```

## Setup and Installation

1.  **Clone or create the project directory:** Ensure all three files (`mcp_server.py`, `agent_loop.py`, `app.py`) are placed in the same root directory.
2.  **Set up environment variables:** Create a `.env` file in the root directory and add your Groq API key:
    ```env
    GROQ_API_KEY=your_groq_api_key_here
    ```
3.  **Verify Model Configuration:** By default, `agent_loop.py` is configured to use `openai/gpt-oss-120b` or `mixtral-8x7b-32768`. Ensure the `MODEL_NAME` variable in `agent_loop.py` is set to a model supported by your active Groq account.

## How to Run

Launch the application using Streamlit from your terminal:

```bash
streamlit run app.py
```

## Usage Instructions

1.  Open the local URL provided by Streamlit in your browser (typically `http://localhost:8501`).
2.  Enter the **Target URL** of the website you wish to scrape.
3.  Define your **Extraction Goal** in plain English. Be specific about the data schema you want (e.g., "Extract all product names and prices into a JSON array of dictionaries containing 'name' and 'price' keys").
4.  Click **Run Extraction**.
5.  Monitor the Process Logs to watch the agent draft code, encounter potential errors, and rewrite its logic to heal the pipeline. 
6.  Retrieve your final structured JSON data and the raw Python code generated by the agent from the output containers.
